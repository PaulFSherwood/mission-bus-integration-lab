# MBIL Exchange Runtime Files

This folder is for runtime exchange files written by the adapter and read by MBIL.

Do not commit generated files from this folder. Keep only this README and `.gitkeep`.

Typical generated files:

- `adapter_status.json`
- `bus1553_A_latest.json`
- `bus1553_B_latest.json`
- `bus1553_messages.jsonl`
- `arinc429_latest.json`
- `discretes_latest.json`
- `analog_latest.json`
- `ethernet_latest.json`
